MetaMask（メタマスク）は、イーサリアムや他のブロックチェーン対応の暗号資産ウォレット兼ブラウザ拡張機能・モバイルアプリです。自分で秘密鍵を管理する「自己管理型ウォレット」なので、最初の ダウンロードとインストールを正しく行い、セキュリティに注意することがとても重要です。

このガイドでわかること

  • メタマスクとは？ウォレットとして何ができるか

  • スマホ（iOS/Android）版メタマスクの導入手順
  • インストール後に必ずやるべきセキュリティ対策
  • よくある質問（FAQ）

1. メタマスク（MetaMask）とは？

MetaMask（メタマスク）は、ブラウザ拡張機能およびモバイルアプリとして提供される暗号資産 ウォレットです。主な特徴は次の通りです。

  • イーサリアムをはじめとする複数のネットワークに対応した暗号資産ウォレット
  • dApps（分散型アプリ）やNFTマーケット、DeFiサービスと簡単に接続できる
  • 拡張機能はChrome・Firefox・Brave・Edgeなど主要ブラウザで利用可能
  • モバイルアプリ版はiOS・Androidの公式ストアからインストールできる
  • 秘密鍵やシークレットリカバリーフレーズはユーザー自身が管理する自己管理型ウォレット

つまりメタマスクは、「Web3の世界に入るための入口」として、多くのユーザーに利用されている代表的なウォレットです。

2. PC向け：MetaMask拡張機能をダウンロード＆インストールする方法

2-1. 対応ブラウザの確認

まずPC（デスクトップ）でメタマスク拡張機能を使う場合、対応ブラウザを用意します。代表的な対応ブラウザは以下です。

  • Google Chrome
  • Mozilla Firefox
  • Brave ブラウザ
  • Microsoft Edge（Chromium版）

これらのブラウザの拡張機能ストアからメタマスクを ダウンロードするのが安全です。できるだけ最新バージョンのブラウザを利用しましょう。

2-2. 公式サイトから拡張機能ページへアクセス

偽サイトや偽拡張機能を避けるため、必ずMetaMask公式サイト経由でアクセスするのがおすすめです。

  1. PCブラウザで 公式サイト（ https://metamask.io）を開く
  2. トップページの「Get MetaMask」や「Download」ボタンをクリック
  3. 自分が使っているブラウザ（Chrome・Firefoxなど）を選択
  4. 各ブラウザの拡張機能ストア（Chrome Web Storeなど）のメタマスクページが開く

検索エンジンで「MetaMask」と検索して直接ストアに飛ぶ方法もありますが、偽アプリをインストールするリスクを減らすために公式サイトからの遷移がより安全です。

2-3. 拡張機能をブラウザに追加する

拡張機能ストアのページに移動したら、次の手順でインストールします。

  1. MetaMaskの紹介ページで、開発者が「MetaMask」または「ConsenSys」など正規の表記か確認する
  2. 評価・レビュー数、ユーザー数が極端に少ない場合は別アプリの可能性がないかチェック
  3. 「Chrome に追加」「Firefox に追加」などのボタンをクリック
  4. ポップアップの確認ダイアログで「拡張機能を追加」を選択
  5. インストールが完了すると、ブラウザ右上にキツネのアイコンが表示される

ブラウザのピン留め機能がある場合は、メタマスクのアイコンをピン留めしておくと、いつでもすぐにウォレットにアクセスできて便利です。

2-4. 初回起動とウォレットの作成／インポート

メタマスク拡張機能のインストールが終わったら、初期設定を行います。

  1. ブラウザ右上のメタマスクアイコンをクリックして起動
  2. 最初の画面で「Get Started（はじめる）」をクリック
  3. 次のいずれかを選択
    • 「Create a new wallet」：新しくウォレットを作成
    • 「Import using Secret Recovery Phrase」：既存ウォレットを復元
  4. ウォレット作成の場合は、利用規約への同意や匿名データ共有の可否を選択
  5. メタマスク用の ログイン用パスワードを設定（PCごとに固有）

この時点ではまだシークレットリカバリーフレーズ（12/24単語など）は表示されていないか、確認ステップがまだ続きます。次のセクションで安全な保管方法を必ず確認してください。

2-5. シークレットリカバリーフレーズの確認とバックアップ

新規ウォレット作成時には、メタマスクから 「Secret Recovery Phrase（シークレットリカバリーフレーズ）」と呼ばれる12単語前後の英単語列が表示されます。これはウォレットを復元するための最重要情報です。

  • 画面の指示に従ってフレーズを表示する
  • 紙に手書きで控えるなど、 オフラインで安全な場所に保管する
  • スクリーンショット、クラウドストレージ、メール、チャットアプリなどに保存しない
  • 誰かにフレーズを教えない（サポートや公式を名乗る相手であっても例外なし）

メタマスク側でフレーズの再確認テストが行われるので、正しい順番で入力して確認が取れたら初期設定は完了です。

3. スマホ向け：MetaMaskアプリをダウンロード＆インストールする方法

メタマスクは モバイルウォレットとしても利用でき、スマホだけでdAppsやNFT、DeFiにアクセスできます。ここではiOS（iPhone）とAndroidでの導入手順を説明します。

3-1. iOS（iPhone）のインストール手順

  1. iPhoneで App Storeを開く
  2. 検索タブで「MetaMask」または「メタマスク」と入力
  3. キツネのロゴで、開発元が正規（MetaMask / ConsenSys など）になっているか確認
  4. 評価・レビュー数が極端に少ない類似アプリはインストールしない
  5. 正規アプリを確認できたら「入手（Get）」ボタンをタップ
  6. Face ID/Touch IDやパスワードでインストールを承認
  7. ダウンロードとインストールが完了したら「開く」をタップ

3-2. Androidのインストール手順

  1. Android端末で Google Play ストアを開く
  2. 検索バーに「MetaMask」と入力
  3. キツネのロゴで、開発元が「ConsenSys Software Inc.」など正規の表記かを確認
  4. ダウンロード数が多く、レビューも十分にある公式アプリを選ぶ
  5. 「インストール」ボタンをタップ
  6. インストール完了後、「開く」をタップしてアプリを起動

ブラウザや外部サイトからAPKファイルを直接ダウンロードしてインストールする方法は、偽アプリのリスクが高いため避けた方が安全です。必ず公式ストアからインストールしましょう。

3-3. モバイルアプリでの初期設定

アプリを初めて起動したら、PC版と同様にウォレットの作成または復元を行います。

  1. MetaMaskアプリを起動し、「Get Started」をタップ
  2. 次のいずれかを選択
    • 「Create a new wallet」：スマホで新しくウォレットを作成
    • 「Import using Secret Recovery Phrase」：PCなど既存ウォレットを復元
  3. 利用規約・プライバシーポリシーを確認し、同意する
  4. アプリ用のパスコード（数字）や生体認証（Face ID・指紋認証）を設定
  5. 新規作成の場合は、シークレットリカバリーフレーズが表示されるので オフラインで保存
  6. フレーズの確認テストに合格すると、ホーム画面（ウォレット画面）が表示される

3-4. PCとスマホで同じウォレットを使うには？

すでにPC版メタマスクにウォレットがあり、スマホ版で同じウォレットを使いたい場合は、 シークレットリカバリーフレーズを使ってインポートします。

  1. PC版メタマスクで、設定メニューからシークレットリカバリーフレーズを確認
  2. 紙などに正しい順番でメモする（他人に見られないよう注意）
  3. スマホ版メタマスクを起動し、「Import using Secret Recovery Phrase」を選択
  4. メモしたフレーズを正確に入力し、スマホ用のパスコードを設定
  5. インポート完了後、PCと同じアドレス・残高が表示されていれば成功

PC版 → スマホ版、スマホ版 → PC版のどちらの方向でも同じ手順で同期できますが、フレーズの入力は必ず 公式アプリ／公式拡張機能の画面のみに限定してください。

4. インストール後に必ずやるべきセキュリティ対策

メタマスクは便利なウォレットですが、セキュリティ対策を怠ると資産を失うリスクがあります。ここでは最低限やっておきたいポイントをまとめます。

4-1. シークレットリカバリーフレーズの鉄則

  • 誰にも教えない：公式サポートや友人を含め、フレーズを要求する相手は全て詐欺と考えてよい
  • スクリーンショット禁止：スマホの写真やPCのスクショはクラウド同期されがちで危険
  • オフライン保管：紙に書く、金属プレートに刻印するなど、インターネットから切り離す
  • 複数箇所に分散保管：火事・盗難などに備えて、安全な場所を2カ所以上に分けるとさらに安心

4-2. 偽サイト・偽アプリの見分け方

  • URLが metamask.io以外の類似ドメイン（例：metamask〇〇.com）に注意
  • 広告枠に出てきたダウンロードリンクは、必ずURLを確認してからクリック
  • App Store/Google Playで開発者名が不自然、レビュー数が少なすぎる場合は要警戒
  • 「〇〇キャンペーンのためにシードフレーズを入力してください」といった案内は100％詐欺

4-3. デバイス側の基本設定

  • PC・スマホともにOSとブラウザを常に最新バージョンに更新する
  • ウイルス対策ソフトやマルウェア対策ソフトを導入する
  • 怪しい拡張機能やアプリは定期的に整理して削除する
  • パスワードはウォレット専用の強力なものを使用し、他サービスと使い回さない

5. よくある質問（FAQ）

Q1. メタマスクは無料で使えますか？

はい、メタマスクの ダウンロードとインストール自体は無料です。ウォレットの作成も無料ですが、実際にトランザクションを行う際にはブロックチェーンのネットワーク手数料（ガス代）が発生します。

Q2. 公式アプリかどうか不安な場合はどうすればいいですか？

まずは https://metamask.ioの公式サイトからダウンロードページに移動し、そこからブラウザ拡張機能ストアやApp Store／Google Playに遷移するのが最も安全です。開発者名・レビュー数・ダウンロード数も合わせて確認しましょう。

Q3. PCとスマホで同じウォレットを使うメリットは？

自宅ではPCブラウザ拡張機能でdAppsを使い、外出先ではスマホアプリで残高確認や簡単な送金を行うなど、状況に応じて柔軟に使い分けられる点がメリットです。ただし、どちらのデバイスもセキュリティ対策を徹底する必要があります。

Q4. ウォレットのバックアップはシークレットリカバリーフレーズだけで十分ですか？

基本的にはシークレットリカバリーフレーズがあればウォレットは復元可能です。ただし、複数の場所に安全に保管し、火災や盗難など物理的なリスクにも備えることをおすすめします。PCのバックアップだけに頼るのは危険です。

Q5. メタマスク以外のウォレットから乗り換えることはできますか？

すでに別の自己管理型ウォレットを使っている場合、そのウォレットのシードフレーズ（互換性のある形式）をメタマスクにインポートして移行できる場合があります。ただし、すべてのウォレットで完全互換とは限らないため、事前に必ず公式ドキュメントやサポート情報を確認してください。

以上が、MetaMask（メタマスク）ウォレットをPCとモバイルで安全に ダウンロード＆インストールするための基本ステップです。最も大切なのは、「公式サイト・公式ストア以外から入手しないこと」と「シークレットリカバリーフレーズを絶対に他人と共有しないこと」です。この2点を守りつつ、Web3の世界を安全に楽しんでください。
